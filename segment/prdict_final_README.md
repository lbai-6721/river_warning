# 河堵预警算法 - 最终版本使用说明

## 功能概述

`prdict_final.py` 是一个功能完善的河堵预警算法，集成了白天和夜间两种场景模式，支持批量图像处理、语义分割、边界提取和时序对比分析。

## 核心特性

- ✅ 支持白天和夜间两种场景模式
- ✅ 完善的错误处理机制
- ✅ 批量图像处理
- ✅ 语义分割识别河床区域
- ✅ 提取河流上下边界
- ✅ 前后帧对比分析
- ✅ 自动跳过无效文件

## 场景模式对比

### 夜间模式 (night)

**适用场景**：低光照、夜间拍摄的图像

| 参数 | 值 |
|------|-----|
| 图像类型 | 灰度图 |
| 处理方式 | 整图处理（不切分） |
| 高斯平滑 | sigma=5（弱平滑） |
| 分辨率 | 1920×1152 |
| 处理速度 | 快 |
| 内存占用 | 低 |

### 白天模式 (day)

**适用场景**：正常光照、白天拍摄的彩色图像

| 参数 | 值 |
|------|-----|
| 图像类型 | 彩色图（RGB） |
| 处理方式 | 切分处理（5×2小块，512×512） |
| 高斯平滑 | sigma=30（强平滑） |
| 分辨率 | 2560×1440 |
| 处理速度 | 较慢 |
| 内存占用 | 较高 |

## 使用方法

### 1. 配置场景模式

打开 `prdict_final.py`，找到第 **314** 行，修改 `SCENE_MODE` 参数：

```python
# 夜间模式
SCENE_MODE = 'night'

# 或者白天模式
SCENE_MODE = 'day'
```

### 2. 配置输入输出路径

修改第 **317-318** 行：

```python
predicted_folder_ = r"./img"      # 输入图像目录
output_folder = './img_out'        # 输出结果目录
```

### 3. 准备输入数据

输入目录结构应为：

```
输入目录/
├── 子文件夹1/
│   ├── image1.jpg
│   ├── image2.jpg
│   └── image3.jpg
└── 子文件夹2/
    ├── image1.jpg
    └── image2.jpg
```

### 4. 运行程序

```bash
python prdict_final.py
```

## 常见问题

### Q1: 如何选择合适的模式？

- **夜间图像**、**灰度图像**、**低光照图像** → 使用 `night` 模式
- **白天图像**、**彩色图像**、**高分辨率图像** → 使用 `day` 模式

### Q2: 为什么有些图片检测不到河床？

可能原因：
- 图像质量太差（过暗、过亮、模糊）
- 图像中确实没有河床
- 场景模式选择不当（尝试切换模式）

程序会自动跳过这些图片并继续处理。

### Q3: 白天模式需要 `img/temp` 目录吗？

是的，白天模式会自动创建 `img/temp` 目录用于存储切分的小块图像，处理完成后可以删除。

### Q4: 如何提高处理速度？

- 夜间图像使用 `night` 模式（比 `day` 模式快很多）
- 减少输入图像的数量
- 使用 GPU 加速（确保 CUDA 可用）

## 错误处理

程序具有完善的错误处理机制：

- ✅ 自动跳过非图像文件
- ✅ 自动跳过无法读取的文件
- ✅ 自动跳过目录和隐藏文件
- ✅ 检测到空结果时跳过后续处理
- ✅ 捕获异常并继续处理其他文件

## 技术细节

### 白天模式图像切分策略

原始图像 2560×1440 → 切分为 5×2 = 10 个小块：

```
[00][01][02][03][04]  ← 第1行，每块 512×512
[10][11][12][13][14]  ← 第2行，每块 512×512
```

每个小块独立进行语义分割，然后拼接回完整掩码。

### 高斯滤波参数说明

- **sigma=5**（夜间）：弱平滑，保留更多细节，适合细节较少的夜间图像
- **sigma=30**（白天）：强平滑，减少噪声，适合细节丰富的白天图像
