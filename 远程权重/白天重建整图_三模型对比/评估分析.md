# 白天重建整图：三模型分割对比与权重说明

> 来源：AutoDL `/root/autodl-tmp/river_warning`；训练代码版本 `e12fa6e`。本目录只包含模型权重与汇总评估文件，不包含原始图片和掩膜。

## 数据与训练设置

- 数据：白天重建完整分析区域（ROI）共 3227 张，每张由既有 5×2 图块重建；重建无法恢复原始采集时被裁掉的区域。
- 划分：训练 1662 张 / 192 个日期组，验证 773 张 / 64 个日期组，测试 792 张 / 65 个日期组；图块及同日样本不跨集合。
- 测试集为相同的 792 张图；三个模型均从随机初始化训练，随机种子 42，输入 512×512，batch size 4，AdamW 学习率 3×10⁻⁴、权重衰减 10⁻⁴，未开启翻转、天气或设备增广。
- 训练时从重建图随机裁取 512×512；推理时以 512×512 图块、步长 384 覆盖完整 ROI，重叠处平均概率后以 0.5 阈值生成掩膜。最大 100 epoch，验证损失连续 20 epoch 未改善则早停，保存最低验证损失的 `best.pt`。
- 清单 SHA-256：`a8e894a6ba80e096bd6847c6a9ee22166ea67f1461d39b8507e2498b29eac24d`。三次训练的 `manifest_sha256` 均一致。

七月只有 71 张图、6 个日期组，月度数值波动更容易受少数日期影响。`weather` 在清单里全部为 `unknown`，因此现阶段无法分析晴雨雾差异。各月份完整指标见各模型的 `test_cohorts.json`。

## 结果解读

LRASPP 的总体河流 IoU 为 0.6847，比 DeepLabV3+ 高 0.0258、比 U-Net 高 0.0457；边界 F1 也是三者最高（0.2720）。它目前是这组白天测试上的优先候选。U-Net 中位推理耗时最短（0.156 秒/张），但召回率最低，漏分河流像素较多。DeepLabV3+ 在七月子集的 IoU 最高，但总体不及 LRASPP。

这些结论只针对当前白天重建 ROI、同一随机种子和这一次固定测试集。没有重复种子、成对差值的日期组 bootstrap 或外部场景测试，不能据此声称模型间差异具有统计显著性，也不能把像素分割成绩直接当作堵江事件预警准确率。

## 文件与复用

每个模型子目录包含：`best_epoch_XXX.pt`（验证损失最优的完整 riverlab 检查点）、`checkpoint_info.json`（轮次和 SHA-256）、`train_config.json`、`train_run.json`、`train_history.csv`、`test_metrics.json`、`test_cohorts.json`、`test_run.json`。`SHA256SUMS.txt` 可用于逐文件校验。权重文件名中的轮次是最佳轮次，可能早于实际停止轮次。

在仓库根目录、数据清单可用时，可用以下命令复评；将模型目录名和权重轮次替换成目标模型，输出目录须为新路径：

```bash
python -m riverlab eval-seg --checkpoint "远程权重/白天重建整图_三模型对比/LRASPP_MobileNetV3Large/best_epoch_028.pt" --manifest datasets/segmentation/day/reconstructed_roi/manifest.csv --output runs/day_lraspp_recheck --device cuda --split test
```

数据清单和图片仍位于仓库忽略的 `datasets/`，不随本目录的 Git 提交分发；复评时清单内容必须与上面的 SHA-256 一致。
