# 旧分类特征核对与修复说明

核查日期：2026-09-27。原始 CSV 与图像未改动。本报告用于修正此前“243对中228对错配”的过度判断，并给出可复核的数据修复顺序。

对 `Classifier_ACC0.93/cnn/area.csv`、`up.csv`、`down.csv` 的243条图像对，以行号保留原始记录，兼容其两种旧时间标识格式（下划线及连字符）后：

| 类别 | 对数 | 含义 |
| --- | ---: | --- |
| 起止小时均与边界表帧名一致 | 134 | 时间标识层面可直接关联；尚未证明数值特征和标签真实 |
| 仅起始小时不同，结束小时一致 | 103 | 全部是2021年标签1；同名源文件夹均有边界表对应的两张图，多为文件夹名/标识问题 |
| 面积对标识无法完整解析 | 4 | 包括仅有单个时间及明显的年份/月格式错误；需人工核对 |
| 两个端点小时都不同 | 2 | 需核对文件夹、图像和行来源 |

此前审计以 `_` 和固定点号格式解析，导致连字符或紧凑日期也被记为错配，从而报出228对。**228不是228条数值特征错误，也不是228条标签错误。**

`up.csv` 与 `down.csv` 的486行图像文件名逐行相同。对 `norm-dis-data` 中同名图像对目录核查：120个目录恰好含对应的两张边界表原图；其余122条在该目录下未找到同名文件夹，另有1条同名文件夹中的图片与边界表不符。这是指定目录内的查找结果，不证明原图在项目其他目录也不存在。

需要优先人工查看的6个面积表行号为 **120、121、142、143、154、182**。其中120、121有同名目录和两张匹配图；其余4条没有在上述目录找到同名文件夹。不要仅凭猜测修正旧标识。

逐行清单：[legacy_pair_reconciliation.csv](../paper_output/data_cleaned/legacy_pair_reconciliation.csv)。可用 `area_csv_row`、`boundary_frame_a`、`boundary_frame_b` 和 `source_folder` 回查。[人工复核模板](../paper_output/data_cleaned/legacy_pair_review_template.csv) 保留243条旧记录，但把图像对与标签均预设为“待核验”，等待填写事件依据和纳入决定。完整机器审计（含三个 CSV 的 SHA-256）：[legacy_pair_audit.json](../paper_output/data_cleaned/legacy_pair_audit.json)。

## 先修身份，再修数值与标签

1. **建立新的唯一图像对 ID。** 以 `up/down` 共识的两个完整图像文件名为依据，记录参考帧与当前帧、精确时间、原面积表行号、旧文件夹名和旧标签。103条起始小时不同的记录在新清单中使用帧名派生的时间；保留旧字符串作追溯字段。不得仅修改原 `area.csv` 的文本。
2. **逐条审核6条明显异常记录。** 4条标识无法完整解析、2条双端小时不同，应由源图或原计算记录确认归属。无法确认时标记“待核”，不进入正式实验。
3. **确认特征数值。** 图像文件名对得上只证明“图片身份”，不证明 `area.csv` 的10个面积差值确实由这两张图的同一套 mask 和算法得到。用户目前找不到旧面积生成脚本，故应从已确认的原图与 mask 重建统一的特征流水线：固定 mask 来源、模型权重或人工标注版本、图像尺寸/ROI、区域划分和特征公式，逐对运行 `riverlab pair-features` 并保存输入与输出哈希。这会形成一套新特征，不能称为对旧数值的恢复。
4. **确认标签语义。** 旧表中标签1的103条均来自2021年 `normal2dis` 目录。用户目前尚不确定它们是否有真实堵江事件依据。应为每对记录事件 ID、地点、发生时间窗口、标注者、证据文件及标签状态（已核验/待核验）；先把旧标签标为“待核验”。目录名本身不是事件真值。
5. **检查有无足够的跨时期正负例。** 旧表2021年有103正/15负，负例仅涉及3个日期；2022年0正/125负。若依旧数据随机按图像对拆分，年份或同源帧信息可能支撑分类器得分。需补有依据的同期负例和其他时期正例，再按日期、共享帧及事件分组，固定测试集。
6. **最后训练与对照。** 确定新清单和特征来源后，在同一划分上做面积阈值、逻辑回归、随机森林、双分支CNN对比，以及面积/边界/二者消融。验证集选模型和阈值，测试只评一次。未经复核的旧0.93准确率不作为论文主结果。

修复优先级是**标签依据和图像对身份 > 一致的特征重算 > 分类训练**。如果无法取得可信的正例事件记录或跨时期正负数据，应缩小论文结论，不宣称独立事件的堵江识别能力。

## 可复现核查命令

在仓库根目录运行：

```powershell
$riverPython = 'D:\anaconda\envs\river-segment\python.exe'
& $riverPython -m riverlab audit-legacy-features --folder Classifier_ACC0.93/cnn --source-pairs ../../norm-dis-data --output paper_output/data_cleaned/legacy_pair_audit.json --rows-output paper_output/data_cleaned/legacy_pair_reconciliation.csv
```

`source-pairs` 可换为保存旧两帧图像对的实际目录。CSV和JSON只作核查，不会改写原始数据；`import-legacy` 对仍有未复核问题的数据保持拒绝导入。
