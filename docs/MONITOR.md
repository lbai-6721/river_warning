# 本地河道监控界面

启动：在已安装项目依赖与 PyTorch 的环境中，仓库根目录执行：

```powershell
python -m riverlab.monitor
# 此电脑已有的环境也可直接使用：
.\scripts\start_monitor.ps1 -Python 'D:\anaconda\envs\river-segment\python.exe'
```

浏览器打开 <http://127.0.0.1:8877>。仅绑定本机，不需要前端构建、额外 Web 框架、外部字体或云服务。端口可用 `--port` 修改。停止终端中的服务使用 Ctrl+C；界面的停止按钮仅停止当前分析任务，当前图像计算完成后生效。

## 工作流

1. 选择白天或夜间及已有图像对，预览原图，点击“开始检测”。
2. 查看分割、变化区域、河体占比和分类结果；对比分析页展示两张叠加图、20 个条带面积占比差和结果来源。
3. “样本回放”从所选样本开始处理若干独立图像对。每对独立判别，不累计成连续告警。
4. 上传 2 张图做单次分析，或上传 3–20 张同一摄像头的连续图片做固定参考序列分析。检查每张图的真实拍摄时间；最早图作为正常参考由操作者保证，系统不能从时间自动证明正常。重复时间、逆序端点、不同分析尺寸会拒绝处理。
5. 检测与告警记录保存在本机，可重新查看和导出 CSV。系统设置保存告警阈值、连续确认/恢复次数和最大观测间隔。

## 分类结果的边界

目前默认加载 `Classifier_ACC0.93/cnn/checkpoint.pth`，严格匹配原 `net.py` 的 CNN；不使用结构不同的 `best_checkpoint.pth`。

已有图像对必须精确匹配 `up.csv/down.csv` 两个端点文件名，特征记录唯一、有限、通过现有审计后，才能使用原始 2×20 边界与 10 维面积特征执行旧分类。已知仅文件夹起始小时不同但端点身份明确的记录可以显示历史分类；6 条未解决的旧记录排除。分数是旧模型的 softmax 输出，未经校准，不能当作真实灾害发生概率。旧标签与旧特征的事件依据仍按原审计文档管理。

**历史特征分类不使用这次新生成的分割 mask**。新分割用于可视化和几何分析，两者来源在界面、数据库及 CSV 中区分。不伪造旧面积特征，不用任意面积阈值代替灾害分类。新上传图片即使文件名相同也不会自动使用历史 CSV。没有配套分类器时 `prediction/score=null`，显示“无法判定”。

要启用新图像完整预测，在操作者维护的配置副本（如被 Git 忽略的 `configs/local.monitor.json`）中给 `profiles.day.classifier` / `profiles.night.classifier` 设置可信的 `riverlab train-cls` 产出 `model.joblib` 路径。该模型必须在相同分割权重、ROI 和参考配对策略下，以预测 mask 的 `pair-features` 训练。服务核对来源、特征类型、分割 SHA-256，复用训练时标准化器、质量门控和冻结阈值。不要配置来自不可信来源的 joblib 文件。

## 图像与模型配置

默认分割模型是本地已下载的日夜 DeepLabV3+，路径见 `configs/monitor.json`。推理沿用 checkpoint 中的滑窗参数，CPU 两线程，按需加载，最近 6 张图的 mask 缓存，跨场景独立模型。

白天训练区域为 2560×1024：接受已经裁好的 ROI，或对 2560×1440 原图裁取 y=208…1232。其他尺寸拒绝静默拉伸。夜间目前使用整张输入及重建模型的滑窗设置；部署前应核对摄像头视角和训练区域，修改配置时同时维护下游特征版本。当前不提供自动相机配准或自动日夜判断，由操作者选择相同视角和日夜模式。

质量门控参数是可调的初始值，不是经现场验证的生产阈值。过暗、过亮、模糊或空 mask 返回无法判定。正常/异常的现场效果须用独立连续事件数据评估，界面运行不意味着已完成效果验收。

## 告警与持久记录

单个图像对异常记为“候选异常”，不是经连续确认的灾害事件。上传序列每个会话单独维护告警状态，采用固定首帧参考；严格递增且未超间隔的有效观测才累计连续次数。异常连续达到阈值触发，连续低于解除阈值恢复；中间分数保持已有告警。缺图、推理错误及无效结果中断连续计数，不能解除已有告警。服务重启后正在运行的任务不续跑，历史结果保留。

所有输出位于被 Git 忽略的 `runs/monitor/`：SQLite 记录、上传图片、分割 mask、叠加图、告警参数。记录包括模型哈希、历史 CSV 哈希/原始行号、配置、参考时间、耗时和结果来源。默认历史界面显示最近 300 条，CSV 导出最多 100000 条。原始数据、模型和历史脚本保持原位。

本版本支持本地图片和有限长度序列回放，尚未接入 RTSP、视频文件解码、多摄像头长期采集或外部消息通知。没有预设或模拟的告警与性能数值。

## 验证

```powershell
python -m unittest discover -s tests -p test_monitor.py -v
python -m unittest discover -s tests -v
```

测试覆盖历史特征身份核对、上传与接口限制、任务隔离、未知观测和断流时的告警保持。真实权重推理由本机已有日夜图像对做冒烟验证，结果属于工程联调，不作为模型准确率评估。
