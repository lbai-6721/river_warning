## 本次确认的数据问题

- 旧白天train/val有2019个原图标识交叉，test为空。
- 旧VOC2023常规划分train/test有4054个完全相同样本；Fold_1虽无同文件交叉，train/test仍有2031个共同原图标识。
- 旧分类 area/up/down 共243对。早期审计把连字符、紧凑日期等旧格式误判为错误，报出228对；重新兼容格式后，134对的小时标识一致，103对仅起始小时不同，4对标识无法完整解析，另2对两个端点小时均不同。逐行文件夹核查显示103对正例的源目录均含对应两张原图，故不能把这103对直接视为特征值错误。原面积数值的生成步骤与标签真实性仍待复核，导入器继续拒绝未经复核的数据。
- 标签与年份强相关：2021年103正/15负（负例仅3个日期），2022年0正/125负；旧CSV不能通过随机按图像对切分证明跨年份堵江识别有效。
- 白天mask存在混合编码；裁剪编号为行列顺序。已在新流程实现显式解码与方向配置，并用真实样本核对。

证据保存在 `artifacts/legacy_split_audit.json`、`artifacts/legacy_feature_audit.json`、`artifacts/verification/dataset_audit.json` 和 `reconstruct_check.json`。这些文件含本地数据标识，按项目约定留在被Git忽略的产物目录。
